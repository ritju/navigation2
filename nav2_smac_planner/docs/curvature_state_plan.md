# Hybrid A* 增加曲率状态的方案

本文只描述方案，不改代码。目标是把搜索状态从 (x, y, θ) 扩成 (x, y, θ, κ)，使全局路径在给定参考速度下满足前轮转向、后轮驱动底盘的转角、转向角速度和转向角加速度限制。

曲率档数不事先指定。相邻档的转角差由一步搜索弧长、参考线速度、转向角速度和转向角加速度算出，再换成曲率。

## 已落实的决定

写代码时按下面这些执行，不再另选。

1. 规划位姿是后桥中心。足迹仍用代价地图上的机器人轮廓，轮廓原点相对后桥的平移按车体坐标加到每个采样位姿上。
2. 45° 是等效自行车模型的中心转角。`κ_max = tan(45°) / L`。
3. 改变曲率档的原语弧长固定为 `primitive_length`。档距只按这个长度计算。曲率档不变的短弧长只在离目标不超过两段 `primitive_length` 时展开，用来挪动回正曲线的起始时刻，不在每个节点上展开。横向偏差大于位置容差的，由更早的长原语消掉。
4. 每次规划由调用方传入当前前轮转角 `start_steering_angle`。规划器不订阅关节话题。未传入时按 0，此时第 9 节不覆盖第一段。传入时第一段从该角度走到最近的曲率档，转速从 0 回到 0，长度用这一小段角差的最短时间，可以短于 `primitive_length`。不把传入角收到档中心再开始积分。
5. 图索引把 `x`、`y` 四舍五入进格，航向、曲率进档。积分和发布的路径使用节点上保存的连续位姿。下一条原语从上一段的连续终点积分，不从航向档中心重开。转角曲线按刚好转完这一档的最短时间生成；剩下的时间保持终点转角，转速为 0，把弧长补满该原语的长度。
6. 0 档只能保持或加一档。最后一档只能保持或减一档。
7. `Δδ` 与 `Δδ_max` 相等时允许。比较写成 `Δδ ≤ Δδ_max + 1e-6`，避免浮点把边界判成超限。
8. 位置容差、航向容差沿用现有参数。到达时曲率档必须是 0° 那一档。航向差用节点上的连续航向，不用航向档中心。档中心在门限内、连续航向在门限外，不算到达。
9. 采样点出图或足迹碰撞，整条原语丢弃。未知栅格继续跟现有 `allow_unknown`。起点落在致命障碍上仍然直接失败。
10. 本方案替换 Hybrid 的 Dubins / Reeds-Shepp 原语，不另加插件。窄通道和 `/enable_backward` 只切换前进或倒车。两套都用同一张曲率档，都不调用 `tryAnalyticExpansion`。`smooth_path`、解析扩展、`trimPathTail` 即使参数打开也不执行。
11. 正 κ 始终是车体左侧。倒车只把线速度取反，转角档不取反。换向只发生在原语端点，此时转速已经是 0。
12. 边代价与现有 Hybrid 一样，是基础代价乘系数，不是把 `change_penalty` 再乘上去。子节点曲率档不是 0° 时系数为 `non_straight_penalty`，保持在弯档上也包括在内。节点另存最近一次非零的档位变化方向；保持档把这个方向原样带下去。本次变化方向与它相反时，系数改为 `non_straight_penalty + change_penalty`。`change_penalty` 默认是 0，加上 0 不会把代价变成 0。倒车再乘 `reverse_penalty`。
13. 节点索引、`max_index` 和邻居越界判断都用 64 位。图仍然是稀疏哈希，不按全图分配。不在配置阶段用地图尺寸拒绝规划。
14. 启发式继续用现有 Dubins / Reeds-Shepp 距离和障碍距离，单位与边代价相同，都是栅格长度。查表前把第三维拆成 `θ_bin = d % 72`、`κ_bin = d / 72`，距离表只用 `θ_bin`。它不含角速度和角加速度，因此不大于同一单位下的几何路径长度。边的基础代价取不小于这段弧长的栅格数，障碍项为 `cost_penalty * 平均代价 / 252`。
15. `nav_msgs/Path` 只写连续积分采样点的 `x`、`y` 和航向。相邻两段首尾是同一个连续位姿，接头处没有半格或 2.5° 的跳变。曲率不另写字段。点距不超过一个栅格。
16. 路径只在速度不超过 `v_ref` 时满足角速度和角加速度。路径消息不带速度。控制器按同一个 `reference_speed` 限制速度。
17. 搜索失败返回空路径。起点非法时仍抛异常。

## 1. 底盘约束

| 量 | 取值 |
|---|---|
| 轴距 L | 0.85 m |
| 后轮轮距 | 0.84 m，只用于足迹，不进入曲率 |
| 最大前轮转角 | ±45°（按等效自行车模型的中心转角） |
| 转向角速度 ω | 0.5 rad/s |
| 转向角加速度 α | 1 rad/s² |
| 参考线速度 `v_ref` | 0.5 m/s |

后桥中心曲率与前轮转角的关系：

```text
κ = tan(δ) / L
κ_max = tan(45°) / 0.85 ≈ 1.176 m^-1
```

45° 已确定为中心等效转角。轮距不进入曲率。搜索位姿是后桥中心。

## 2. 由弧长和速度计算曲率档

每条原语在端点处的转向角速度都是 0。这样一步结束时，下一步既可以继续打方向，也可以反向打，不必再增加转速这一维状态。

一步的时间是：

```text
T = Δs / v_ref
```

在时间 T 内，从转速 0 出发再回到转速 0，同时不超过 ω 和 α，能转过的最大角度是：

```text
若 T ≤ 2ω/α（默认参数下即 T ≤ 1 s）：
    Δδ_max = α * T² / 4

若 T > 2ω/α：
    Δδ_max = ω * T - ω² / α
```

默认参数下第二条是 `Δδ_max = 0.5 * T - 0.25`。T 不超过 1 s 时，角速度上限还没加上去，起作用的是角加速度。

切档顺序：

1. 计算 `Δδ_max` 时，Δs 只用 `primitive_length`。保持档的短弧长不参与档距。变档原语用这个弧长。
2. `v_ref` 取这条全局路径承诺能跟踪的最高速度。
3. 用上面的式子得到 `Δδ_max`。
4. 在 −45° 到 +45° 之间按不超过 `Δδ_max` 的步长取档，0° 必须单独占一档。步数取 `ceil(45° / Δδ_max)`，实际档距为 45° 除以该步数。
5. 每个转角档换成 `κ = tan(δ) / L`。

档距小于 `Δδ_max` 仍然可行，只是档更多。档距大于 `Δδ_max` 时，这一步在给定速度下打不完，搜索不得使用这种切分。

默认 `v_ref` = 0.5 m/s、Δs = 0.65 m 时，T = 1.30 s，`Δδ_max` ≈ 0.40 rad ≈ 22.9°。45° / 22.9° 向上取整为 2 步，实际档距 22.5°，得到 5 档：

| `κ_bin` | δ | κ = tan(δ) / L |
|---|---|---|
| 0 | -45° | -1.176 m^-1 |
| 1 | -22.5° | -0.487 m^-1 |
| 2 | 0° | 0 |
| 3 | +22.5° | +0.487 m^-1 |
| 4 | +45° | +1.176 m^-1 |

这 5 档只是该组默认参数的结果。把 Δs 改成 0.40 m 时，T = 0.80 s，`Δδ_max` ≈ 0.16 rad ≈ 9.2°，从 0° 到 45° 需要 5 步，共 11 档。弧长若只有约 0.07 m，`Δδ_max` 约为 0.3°，档数会到一百以上，应加长 Δs，而不是维持过粗的档距。

若希望档距正好是某个 `Δδ`，最短弧长反过来由同一条约束确定。`Δδ` > ω²/α（默认 0.25 rad）时：

```text
T_min = ω/α + Δδ/ω
Δs_min = v_ref * T_min
```

22.5° 对应 `Δs_min` ≈ 0.643 m，所以上面的默认弧长取 0.65 m。只按角速度估算会得到约 0.39 m，角加速度会把这段路程少算约 0.25 m。

## 3. 必须关掉的功能

关掉解析扩展，也就是 `AStarAlgorithm::createPath` 里对 `AnalyticExpansion::tryAnalyticExpansion` 的调用。这是当前搜索在靠近目标时用 Dubins 或 Reeds-Shepp 整段接到目标的快速连接。曲线由圆弧和直线拼接，接点曲率在 0 与 ±`κ_max` 之间跳变，和 κ 状态冲突。

一并取消它内部「沿父节点每次回退 5 个、最多 8 次」的更早起点重连。`analytic_expansion_ratio` 和 `analytic_expansion_max_length` 在本模型下不再参与规划。

窄通道和 `/enable_backward` 仍可在前进与倒车之间切换，但两种模式都不再做解析扩展。倒车只增加反向原语，不恢复 Dubins / Reeds-Shepp 捷径。

同时关掉现有 `Smoother::smooth`。它的坐标梯度下降不约束曲率，首尾 `enforceStartBoundaryConditions` / `enforceEndBoundaryConditions` 又会用 Dubins 曲线覆盖端点。搜索得到的 κ 连续路径经过这一步会重新出现曲率阶跃。本模型输出的路径直接使用原语积分采样点。

## 4. 状态

逻辑状态为栅格坐标、航向档、曲率档：

```text
(x, y, θ_bin, κ_bin)
```

航向保持现有 72 档，每档 5°。曲率档数 `Nκ` 由第 2 节算出。正转角为左转。档距在转角上均匀，在曲率上不均匀，因为 tan(δ) 在大转角处更陡。运动约束按转角档检查，积分时用对应的 κ。

节点索引把曲率档并进原来的第三维，避免再改 A* 队列的维数约定：

```text
Nθ = 72
d = θ_bin + Nθ * κ_bin
index = d + Nθ * Nκ * x + Nθ * Nκ * W * y
```

`getSizeDim3()` 返回 `72 * Nκ`。默认参数下 `Nκ` = 5，第三维为 360。同一格、同一航向、不同曲率是不同节点。每个节点的后继仍是最多 3 个（曲率档减一、保持、加一），倒车模式下再乘以前进/后退两套。

节点索引、`AStarAlgorithm::createPath` 里的 `max_index`，以及邻居回调里的越界比较，都用 64 位。现在的 `getSizeX() * getSizeY() * getSizeDim3()` 是 32 位乘法，4000×4000、第三维 360 时约 5.8×10⁹，会溢出，合法节点会被当成越界丢掉。图仍是稀疏哈希，不按这个乘积分配内存。

连续位姿存在节点上，供下一条原语积分和最终路径使用。索引用四舍五入后的 `x`、`y`，以及最近的航向档、曲率档。不用向零截断。下一条原语不从航向档中心重开，所以上一段的终点就是下一段的起点。

0° 那一档记为 `κ_straight`。默认 5 档时它是 2。起点节点的索引曲率档是传入角最近的那一档，节点上另存传入的连续转角。目标曲率档是 `κ_straight`。到达同一位置但前轮未回正不算到达目标。

## 5. 运动原语

从曲率档 i 只生成落在档位范围内的相邻档和保持档。0 档只有保持和加一档。最后一档只有保持和减一档。禁止跨档。`Δδ` 不超过 `Δδ_max` 才生成，相等时允许。

传入的起点转角若不在档上，第一段单独处理：δ(0) 是传入角，δ(T) 是最近的曲率档，转速两端都是 0。长度用这一小段角差的最短时间，可以短于 `primitive_length`，剩下的时间不再补满到 `primitive_length`。这一段结束以后，后续原语才从档上出发。未传入转角时按 0，第 9 节不覆盖第一段。

一步弧长为第 2 节使用的 Δs。转角曲线按时间生成，不把曲率沿弧长画成直线。设档 i、j 的转角为 `δ_i`、`δ_j`，`Δδ = δ_j - δ_i`。端点条件是：

```text
δ(0) = δ_i
δ(T) = δ_j
δ 的导数在 0 和 T 处都是 0
|dδ/dt| ≤ ω
|d²δ/dt²| ≤ α
T = Δs / v_ref
```

`|Δδ|` 不超过 ω²/α（默认 0.25 rad）时，用三角形转速：先以角加速度 α 加速，到中点再以 α 减速到 0。超过该值时，用梯形转速：以 α 加速到 ω，保持，再以 α 减到 0。曲线时长取刚好转完 `Δδ` 的最短时间。剩下的时间保持终点转角，转速为 0，直到弧长补满 `primitive_length`。不把加速度降下来去铺满整个 Δs。

位置和航向用自行车模型积分，采样步长不超过一个代价栅格：

```text
κ(t) = tan(δ(t)) / L
dx/dt = v_ref * cos(θ)
dy/dt = v_ref * sin(θ)
dθ/dt = v_ref * κ(t)
```

积分起点是当前节点保存的连续位姿，不是航向档中心。原语在车体坐标系预计算，扩展时用这个连续航向旋转。i = j 时 δ 为常数，转速保持 0。δ = 0 是直线，否则是半径 1/|κ_i| 的圆弧。i 与 j 不同时，δ(t) 走上面的三角或梯形，再接一段终点转角保持。终点的连续位姿原样存进子节点。索引用四舍五入后的位置、最近航向档和目标曲率档。

改变曲率档的原语长度就是 `primitive_length`。从 ±45° 回到 0° 要连续两段，大约 1.30 m，不能用到目标的直线距离和其中一段的 0.64 m 比较后提前返回空路径。开过目标、绕行或倒车回来都留给搜索。搜完仍没有满足第 6 节到达条件的节点，才返回空路径。

曲率档不变的短弧长取分辨率的整数倍，最长不超过 `primitive_length`。只在节点到目标的距离不超过两段 `primitive_length` 时展开，用来沿当前航向挪动下一次变档曲线的起点。不在每个节点上展开，避免 0.05 m 分辨率下每个节点多出十几条后继。短直线消不掉大于位置容差的横向偏差，那段偏差要由更早的长原语消掉。不允许原地打方向。

在这个同样的目标邻域里，对当前连续位姿做一次收束，用来代替解析扩展。从当前曲率档出发，按逐档转角曲线走到 `κ_straight`，最后一段直线的长度按剩余距离取，可以短于 `primitive_length`。终点要同时满足位置容差、连续航向门限和 0° 曲率档，并且整段足迹无碰撞。接不上就继续用原语搜。不用 Dubins 或 Reeds-Shepp 曲线。

倒车时线速度取反，正 κ 仍是车体左侧，转角档不取反：

```text
dx/dt = -v_ref * cos(θ)
dy/dt = -v_ref * sin(θ)
dθ/dt = -v_ref * κ(t)
```

换向时曲率档不重置：前轮转角在停车换向时不会跳变。因为每条原语结束时转速已经回到 0，换向后的下一段仍只走到相邻档。

预计算表只存车体坐标。键是 (`κ_bin`, Δκ, 弧长, direction)。改变曲率的前进原语有 `Nκ * 3` 条量级；短的保持档按弧长再乘一份，且只在目标邻域使用。倒车再加一倍。每条保存：

- 相对起点的位移、航向增量、终点曲率
- 车体坐标采样点 (x, y, Δθ, κ)，间距为一个栅格分辨率

不保存终点航向档，也不按 72 个起点航向各存一份再只做平移。扩展时用节点的连续航向旋转、平移。到达的连续航向等于当前连续航向加上航向增量，索引用这个角收成最近的档。`v_ref`、弧长、轴距、角速度或角加速度变化时，先重算曲率档，再重算整张表。

碰撞检查使用采样序列，不用只查终点。采样点出图，整条原语丢弃。足迹在每个采样位姿上检查，位姿先换到足迹原点再查。任一点碰撞则该后继丢弃。未知栅格是否可走跟现有 `allow_unknown`。默认弧长 0.65 m 会跨过多个栅格，只查终点会穿过障碍。起点足迹落在致命障碍上，规划直接失败。

## 6. 搜索流程

1. 按第 2 节生成曲率档。起点索引的曲率档是传入角最近的一档，节点上的连续转角是传入角本身。先走第 5 节的第一段，把它收到该档并且转速回到 0。目标索引的曲率档是 `κ_straight`。
2. Hybrid A* 主循环保持「取最小 f、标记访问、扩展后继」。
3. 不调用 `tryAnalyticExpansion`。离目标不超过两段 `primitive_length` 时，才展开短的保持档，并尝试第 5 节的收束。收束成功就回溯。
4. `getNeighbors` 读取当前 `κ_bin`，取出相邻档和全长保持档。只在目标邻域额外取出短的保持档。倒车模式同时取出反向原语。
5. 碰撞检查用候选连续位姿，先不要写入节点。现有 `getNeighbors` 在比较 g 之前就 `setPose`，更差的父节点会盖掉连续位姿。只有 `g` 更小、且节点还没弹出时，才写入连续位姿、采样点、父指针和上一次非零变档方向。保持档把父节点的变档方向原样复制。已经弹出的节点不再改。
6. 基础代价用栅格长度，不用米。分辨率记为 `res`，平均代价先除以 252，与现有障碍启发式一致。`cost_penalty` 默认是 2：
   - 基础代价 = (本段弧长 / res) ×（路程权重 + `cost_penalty` × 平均代价 / 252）
   - 子节点曲率档不是 `κ_straight` 时，乘 `non_straight_penalty`。保持在 ±22.5° 或 ±45° 上也乘
   - 本次档位变化方向与节点记下的上一次非零方向相反时，系数用 `non_straight_penalty + change_penalty`，与 `node_hybrid.cpp` 里现有写法一致。不把代价再乘一次 `change_penalty`
   - 倒车原语再乘 `reverse_penalty`
   - 路程权重小于 1 时，启发式也乘同一个权重，否则下界不成立
7. 启发式取「障碍距离」和「Dubins 或 Reeds-Shepp 距离」的较大值，两者都在栅格坐标里。第三维先拆开：`θ_bin = d % 72`，`κ_bin = d / 72`。`getCoords` 和 `getDistanceHeuristic` 只用 `θ_bin`。不把打包后的 `d` 当成航向档。同一位姿的各曲率档共用这个 h。
8. 不靠 `isGoal` 的指针相等判断到达，也不用 `goalHeadingSatisfied` 的航向档。弹出的节点若同时满足下面三条，就回溯成功：连续位置与目标的距离不超过现有 `tolerance`（默认 0.25 m）；连续航向差不超过现有航向门限；曲率档是 `κ_straight`。`getHeuristicCost` 里记下的最近节点也必须先通过这三条。
9. 回溯时把每条边上的连续采样点按顺序写入 `nav_msgs/Path`。前一段的终点就是后一段的起点，只写一次。每个点写 `x`、`y` 和积分航向。曲率不写入路径。不附加推荐速度。
10. 搜索失败返回空路径。起点非法时抛异常。不调用 `tryAnalyticExpansion`、`Smoother::smooth` 和 `trimPathTail`。

## 7. 和现有代码的对应关系

| 现有位置 | 本方案 |
|---|---|
| `NodeHybrid::Coordinates` 的 x, y, θ | 增加 `κ_bin`。相等比较包含曲率档 |
| `NodeHybrid::getIndex` | 第三维改为 `θ_bin + Nθ * κ_bin`，索引用 64 位。`x`、`y` 四舍五入 |
| `HybridMotionTable::initDubin` / `initReedsShepp` 的三条或六条圆弧 | 改为第 5 节的转角曲线积分表 |
| `getProjections` 在比较 g 之前 `setPose` | 候选位姿先做碰撞检查。只有 g 更小且未弹出时才写入连续位姿 |
| `a_star.cpp` 中的 `tryAnalyticExpansion` | 删除 Dubins / Reeds-Shepp 调用。目标邻域改用第 5 节的逐档收束 |
| `getDistanceHeuristic` 的 Dubins / Reeds-Shepp 查表 | 保留，作为下界 |
| `SmacPlannerHybrid` 在窄通道切换运动模型 | 保留前进/倒车切换；两套原语都带曲率档；两套启发式缓存仍只存位置和航向 |
| `Smoother::smooth`、解析扩展、`trimPathTail` | 不调用 |
| 路径回溯只记录节点 | 回溯时展开原语采样点，只写位姿 |

`Node2D` 和 `SmacPlanner2D` 不使用本状态。

## 8. 参数

| 参数 | 默认 | 作用 |
|---|---|---|
| `wheelbase` | 0.85 | 轴距，米 |
| `max_steering_angle` | 0.785398 | 最大转角，弧度，45° |
| `max_steering_rate` | 0.5 | 转向角速度，rad/s |
| `max_steering_accel` | 1.0 | 转向角加速度，rad/s² |
| `reference_speed` | 0.5 | 原语所保证的最高跟踪速度，m/s |
| `primitive_length` | 0.65 | 单条原语弧长，米。与上一项一起决定档距 |
| `start_steering_angle` | 由调用方每次传入，缺省 0 | 当前前轮转角。缺省时第 9 节不覆盖第一段 |
| `enable_analytic_expansion` | false | 固定关闭 |
| `smooth_path` | false | 本模型下固定关闭 |

曲率档表不作为独立参数手填。初始化时由 `primitive_length`、`reference_speed`、`max_steering_rate`、`max_steering_accel` 和 `max_steering_angle` 按第 2 节生成。

`minimum_turning_radius` 改为由 L / tan(`δ_max`) 推导，供旧的距离启发式使用。它不再单独决定原语形状。

`reference_speed` 取路径承诺能跟踪的最高速度。按该速度生成的档距，更低速度一定跟得上。把参考速度调高会减小 `Δδ_max`，档数增加。把弧长调短同样会增加档数。二者都变小时，不得沿用按长弧长算出来的粗档。

## 9. 路径应满足的性质

记输出路径采样点上的前轮转角为 δ，由 `δ = arctan(κ * L)` 还原。采样点来自连续积分，段与段首尾重合。第一段从传入角走到最近曲率档。在调用方传入的起点转角和 `v_ref` 下：

- 每个采样满足 |δ| ≤ 45°
- 相邻两个原语端点的曲率档差不超过 1，转角差不超过第 2 节的 `Δδ_max`
- 每条原语起点和终点的转向角速度都是 0，接头两侧转角相同，相邻点重算的曲率不出现半格跳变造成的尖峰
- 原语内部以及接头处 |dδ/dt| ≤ 0.5 rad/s，|d²δ/dt²| ≤ 1 rad/s²
- 目标点落在 0° 曲率档，且在现有位置容差和航向容差内
- 规划过程中解析扩展次数为 0，平滑和路径尾部裁剪次数为 0
- 足迹沿采样点无碰撞
- 搜索失败时路径为空；起点在致命障碍上时规划直接失败
- 起点转角未传入、按 0 处理时，以上转角限制不覆盖第一段
